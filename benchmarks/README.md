# 1차 검증 기록

2026-11-05, Lion Linux x86-64에서 Gaussian 16 Revision B.01과 YoungCC 0.1.0을 비교했다. YoungCC는 Python 3.12.3, NumPy 2.5.4, SciPy 1.18.1을 사용했다. Gaussian은 공유 메모리 프로세서 1개, YoungCC는 OpenBLAS 스레드 1개로 설정했다. 두 프로그램 모두 6개 케이스에서 수렴했다.

[Gaussian 16 상세 결과](gaussian16/lion_results.json)에 오차, 밀도 평가점, 전자 수, 수렴 사이클, 경과 시간이 있다. 최대 궤도 에너지 절대 오차는 2.29e-8 Eh, 최대 밀도 평가점 오차는 7.63e-10 e/bohr³, 최대 전자 수 오차는 1.78e-15 e였다. 벡터의 상대 오차는 최대 절대 차이를 참조 벡터의 최대 절댓값으로 나눈 값이다. 경과 시간은 각 프로그램의 측정 범위와 출력 정밀도가 달라 성능 우위를 판단하는 데 사용하지 않았다.

[PySCF 2.15.0 독립 교차검증](pyscf_results.json)에서 6개 케이스의 총 에너지 최대 차이는 5.10e-8 Eh였다. PySCF는 검증 스크립트에서만 사용한다.

## 오차와 재검증

- H₂O LDA 격자를 기본값 (80, 24, 48)에서 (120, 40, 80)으로 늘리면 총 에너지가 -74.732104897475 Eh로 바뀌고 G16과의 차이는 1.97e-9 Eh로 감소했다. (160, 56, 112)에서는 -74.732104899662 Eh였다. 이 변화는 기본 격자의 구적 오차가 차이의 주요 성분임을 보여 준다. 남은 차이에는 두 프로그램의 유한 격자와 출력 정밀도가 영향을 줄 수 있다.
- G16은 `SVWN5` 입력의 방법 이름을 로그에서 `RS-VWN5`로 출력했다. 비교기는 하이픈을 정규화하고 동일한 6개 실제 로그와 체크포인트로 재검증했다.
- Lion 기본 Python에 `ensurepip`가 없어 시스템 패키지를 바꾸지 않고 작업 디렉터리의 uv로 의존성을 설치했다. Lion Python 3.12, WSL Ubuntu Python 3.11, Windows Python 3.12에서 테스트 18개를 통과했다.
- Windows x64 CLI 실행 파일로 6개 예제의 수렴을 확인했다. GUI 실행 파일에서는 기본 H₂ LDA 계산의 반복 표시와 한글 경로에 JSON 및 로그 저장을 확인했다.

## 검증 범위

에너지 비교는 제공된 세 구조에 한정된다. 밀도 비교는 지정한 소수의 공간 좌표를 사용했다. 열린껍질, 추가 원소와 기저, 기하 최적화, 진동수, TS 탐색, 병렬화는 1차 구현 범위 밖이다.

2차 개발은 회전·병진 및 격자 수렴 회귀 검증을 확장하고, 기울기 구현과 유한차분 검증을 거쳐 구조 최적화를 추가하는 순서가 적합하다. 최적화가 안정화되면 Hessian, 진동수, TS 탐색을 이어서 검증할 수 있다.
